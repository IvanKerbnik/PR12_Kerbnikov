## Описание программы

Программа представляет собой простое приложение для создания и хранения заметок. Она позволяет записывать важные мысли и списки дел.

### Необходимые условия

Для корректной работы программы на компьютере должны быть установлены следующие компоненты:
* Операционная система Windows, Linux или macOS.
* **Python** версии 3.8 или выше.
* *Библиотека Tkinter* (Обычно встроена в Python).

## Установка

Чтобы запустить проект на вашем компьютере, выполните следующие шаги:

1. Склонируйте репозиторий на свой компьютер.
2. Перейдите в папку с проектом.
3. Установите необходимые зависимости, выполнив команду в терминале:
   ```bash
   pip install -r requiments.txt
4. Запустите программу:
   ```bash
   python main.py
   
## Использование

После запуска программы открывается главное окно. Вот пример кода, который отвечает за создание этого окна:
```python
import tkinter as tk

root = tk.Tk()
root.title("Мои заметки")
root.geometry("400x300")
root.mainloop()
```
